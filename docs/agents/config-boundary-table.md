## Collision Decision: agents/*.agent vs .agents/agents/N.md

The spec mentions a hypothetical `.agents/agents/<n>.md` format (from Claude Code's emerging convention). This repo does NOT use that format. The decision:

**`agents/*.agent` files are canonical.** They are the only format parsed by the backend (`api/services/agentfile_parser.py::build_capabilities_summary`). The ostk agentfile DSL (`FROM-PROFILE`, `PROMPT`, `TOOL`, `LIMIT`, `PIN`, etc.) is richer than a plain markdown file and is already integrated into the Agents page UI.

A `.agents/agents/<n>.md` format is not generated from `agents/*.agent` and does not generate `agents/*.agent`. They are independent. If Claude Code natively starts reading `.agents/agents/*.md` files in a future version, that path could co-exist, but today only `agents/*.agent` is active. Nothing generates one from the other.
