## From roadmap: roadmap.md

Recent specs widget on the dashboard

## What we want
Add a widget to the dashboard that shows the 5 most recently created or updated specs. Users should be able to click any spec in the list to open it directly, making it faster to resume work without navigating through the full specs list.

## Acceptance criteria
- [ ] Widget displays spec title and last-modified timestamp for the 5 most recent specs
- [ ] Clicking a spec in the widget opens that spec in the main view
- [ ] Widget shows "No specs yet" message when the user hasn't created any specs
