# URL conventions for youros

The public brand domain is **`getyouros.com`**. The bare `youros.com` is owned by a squatter (HugeDomains, $2–5k asking). Every external surface needs to point people at `getyouros.com` so we don't bleed organic interest to the squatter's parking page.

## Rules

**Canonical:** `getyouros.com`. Always. Never abbreviate to "youros" in any external surface.

**`your-os.net`:** redirect-only. It exists to keep squatters off a typo variant. Never put it on a business card, slide, conference talk, social bio, GitHub link, email signature, or anywhere else a human reads it.

**Voice script for talks and demos:** "get youros dot com" — say the "get" out loud every time. A listener cannot hear a missing "get"; if you say "youros dot com," they will type `youros.com` and land on the squatter.

## What this applies to

External surfaces only:

- Marketing site, blog, press release
- Slides, conference talks, demos
- Business cards, swag, packaging
- Social bios (X, LinkedIn, GitHub profile, Bluesky)
- Email signatures
- README links in any public repo
- Podcast/interview mentions

Internal code and comments can keep saying "youros" or "torios" as they always have. This is about how the brand reaches the outside world, not internal naming.

## Quick check before publishing anything

1. Does the URL appear as `getyouros.com`, never `youros.com`?
2. If spoken aloud, does the script say "get youros dot com"?
3. Is `your-os.net` absent from the surface?

If all three are yes, ship it.

## When to revisit

If Search Console shows >100 monthly searches for the term "youros" by month 3 after the holding page goes live, and direct-traffic share to `getyouros.com` is <30%, the squatter is intercepting real demand and we should buy `youros.com` for $2–5k. Until then, hold and follow these conventions.
