## What's new

### The Arcade
The Break Room is now **The Arcade**. The name changed everywhere it shows up (left nav, page header, and the feature flag), and all seven games got an art pass so they look finished instead of placeholder.
- **Games recover after a dev restart**: if the server restarts while a game tab is open, the tab used to get stuck on an error screen because it was holding an old code file. It now reloads itself automatically so you never land on the error page (→1745).

### Drive sorting
The Drive file list can now be sorted three ways, and it defaults to the one people actually want.
- **Last opened** (the new default): the files you just looked at show up first. This fixes the complaint that slides you opened moments ago were not appearing near the top.
- **Last edited** and **Date created** are also available from a simple control. Your choice is remembered between visits.

### Specs page
- **Edit and delete are now plain icons**: the three-dot menu on each spec card is gone, replaced by a pencil and a trash can. You can rename a spec right in place (→1748).
- **Scratch notes no longer clutter the list**: diagnosis and debug notes that agents drop into the drafts folder are filtered out, so only real specs show up. When a spec's work is finished, the spec is tidied away automatically (→1749).
- **Leftover test files stay hidden**: placeholder specs created by the test suite no longer leak into your live Specs view (→1751). A follow-up fix made sure this filtering never hides a real spec you actually named (for example one titled "Test plan" or "e2e checkout flow").
- Two internal specs were brought up to date (→1746, →1747).

## Reliability
- **Backend recovers on its own (~1 second)**: on a Mac, the backend now starts automatically and is supervised so that if it ever stops, it comes right back without you doing anything. A separate safety check only steps in to clear a stuck process, so the two never fight over the port (→1744). The app's recovery message now just says it is reconnecting instead of asking you to run a command.
- **No more stalls under load**: the first request after a quiet period used to be able to wedge the whole backend while it rebuilt its agent snapshot. That rebuild now happens once and is shared, so the app stays responsive (→1687, →1738).

## Test hygiene
Twenty-three tests that were failing or flaky were made reliable. None were product bugs; they were tests reading shared state instead of their own.
- Task "in progress" and session-coordination tests now set up their own data and event loop, so they pass no matter what ran before them.
- Chat and roadmap tests were updated to expect the current "Tasks" wording instead of the old "tasks" wording.
- Worktree, Slack, calendar, and task-list-dedup tests were isolated from live project data.
- A follow-up item (→1754) tracks finding the one test that leaves a leftover mock behind.

- Frontend: 2954 tests pass, TypeScript build clean.
