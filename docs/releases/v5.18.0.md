# v5.18.0

- Two agents started at the same second no longer show each other's status text on the board, and an agent hidden by that mix-up shows under its own name again.
- The app is faster: each page loads the first time you open it instead of all of them up front, and the long task and agent lists draw only the rows on screen.
- Spawning an agent with no agent file on the Gemini runtime now returns a clear message that names what is missing and how to fix it, instead of a confusing error.
