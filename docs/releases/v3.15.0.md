# v3.15.0

## What's new

### Gemini Captures
Save your gemini.google.com chats into yourOS automatically. Install the Chrome extension once and your future Gemini conversations show up on the MyGems page.

### Gem chat polish
- Assistant replies now render markdown: bold, italic, numbered lists, code blocks. Previously you'd see raw asterisks.
- Threaded replies stay scoped to the thread you replied in. They no longer bleed into the main chat.

### Clearer Gems vs Agents
Each Gem and Agent now shows a one-line role subtitle so it's easier to tell them apart at a glance.

### Friendlier onboarding
The Gemini Captures empty state now shows numbered install steps inline instead of pointing at a developer README. New "Tracking" step in the onboarding wizard with three options + folder picker.

## Reliability

- Backend wedge protection: py-spy thread dump captured automatically before SIGKILL when the watchdog detects a deadlocked backend, so the cause is diagnosable.
- Port 8000 double-bind fixed in the dev backend launcher.
- Task store and API task store now stay in sync across all close paths.
