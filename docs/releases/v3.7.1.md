# yourOS v3.7.1

## Bug fixes

**Faster agent list.** The agents page was sometimes slow to load when your session had a long history. It now loads in under a second.

**No false "Roadmap ready" alerts.** A notification was appearing even when no roadmap had been created. Fixed.

**Tasks no longer block each other.** Running two tasks at the same time could fail with a conflict error. Each task now uses its own lock so they run independently.

**Specs page works correctly.** Navigation and test coverage for the Specs page are aligned after the rename from Plans.

## How to update

```
cd ~/myos
./update.sh
```
