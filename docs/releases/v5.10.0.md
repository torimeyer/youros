## What's new

- **Easier first-time install**: The setup guide now leads with the standard install command everyone can use, and marks the sign-in-key method as a contributors-only option. New people no longer hit a confusing permission error on their first try.
- **Text yourOS from your own phone notes**: Messages you send to yourself (note-to-self) now reach yourOS, with a safeguard that prevents back-and-forth reply loops.
- **Your trusted contacts stay put**: Updating your settings no longer erases your saved trusted contacts list.
- **Plans and their statuses behave correctly**: Draft plans no longer move forward on their own, and plan status changes save reliably.
- **More reliable release checks**: The install and end-to-end safety checks were tightened so the release gate is trustworthy.
