# yourOS v3.7.2

## Stability and reliability

**Agents spawn reliably.** A timing issue could cause agents to start with no instructions, producing empty results. The prompt is now written to a file before the agent starts, so it's always available.

**Old agents clean up automatically.** Completed agents older than 7 days are removed from the list automatically, so the Agents page stays fast.

**Backend won't spawn when overloaded.** If the system is busy, new agent spawns are rejected with a clear message instead of silently failing.

**Interrupted tool calls get retried.** When a tool call fails because of a connection drop (not because you cancelled it), it's automatically queued for retry on your next message.

## Session improvements

**Worktrees clean up on start.** Old temporary workspaces from finished agents are removed when a new session begins. Stale ones older than 7 days trigger a warning.

**Bridge hook handles edge cases.** Read-only agents (like search and planning) no longer get blocked by the isolation hook. Empty lock lists are accepted correctly.

## Smoke test fix

**Release gate runs from ostk.** The end-to-end test script no longer hangs when run through ostk bash.

## How to update

```
cd ~/myos
./update.sh
```
