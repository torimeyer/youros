# myOS v3.8.0

## Jira and Confluence

**Connect your Atlassian account.** Link Jira and Confluence from the Integrations page. Your projects, boards, and spaces show up in the app.

**Jira tickets in your Inbox.** New and updated Jira issues appear as notifications. A background poller checks every few minutes so you do not have to refresh.

**Comment without leaving.** Open a Jira ticket from your Inbox and reply right there. The comment posts back to Jira.

**Two-way actions.** Change status, assign, and transition Jira issues from inside myOS. Changes sync back to Atlassian.

## Slack setup

**Configure Slack from the app.** The Slack integration page now has a form for your credentials instead of asking you to edit a config file. The Connect button stays disabled until the setup is valid.

## Settings

**Tabs instead of scrolling.** Settings sections are now tabs. Click a section and only that section shows. No more hunting through a long page.

**Removed unused controls.** Color mode, font size, icon style, and dashboard layout toggles are gone. They were not wired to anything.

## Agents

**Cleaner template detail.** When you open an agent template, the description and prompt no longer show twice. The capabilities section is removed since agents declare their own scope now.

## Sidebar

**Lighter utility links.** What's New, Tour, Usage, and Settings sit below a separator with smaller text so they do not compete with your main navigation.

## Agent reliability

**Agents keep their tools in worktrees.** The ostk connection is now symlinked into agent worktrees so background agents have full access to coordination tools.

**Graceful fallback.** If an agent runs in a worktree without a local ostk connection, it falls back to standard tools instead of failing.

**No more premature completion.** A timing issue that could mark agents as finished before they started has been fixed.

## How to update

```
cd ~/myos
./update.sh
```
