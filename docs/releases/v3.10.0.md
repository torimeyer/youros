# myOS v3.10.0

**Focus, specs, and polish.** Four new features to help you stay in flow, build better specs, and find things faster.

## New features

### ADHD Mode
A focus layer built into myOS. Enable it in Settings and you get: a gentle check-in notification when you've been away for a while, a welcome-back summary of what was happening when you left, and a focus mode that dims distractions while you're heads-down on a task.

### SDD Wizard
A step-by-step wizard that helps you write a Software Design Doc for any feature. Answer a few questions and myOS drafts the spec, fills in the context it already knows (open tasks, linked files, recent agents), and saves it to your specs library.

### Agents Insights Tab
Each agent now has an Insights tab that shows a summary of what it did, which files it touched, and how long it ran. No more digging through transcripts to understand what happened.

### Editable Agent Template Aliases
Every agent template now has an editable alias. Rename a template to something that fits your workflow and the new name shows everywhere: the picker, the Agents list, and the command bar.

### Settings Nav Cleanup
Data Management and Shared Links now live exclusively under Privacy & Data. They no longer appear as separate top-level items, so the Settings sidebar is shorter and easier to scan.

## Stability and reliability

Hooks now fail open instead of blocking when the coordination socket is unavailable. Agents commit directly onto the main branch when their work is complete, and orphan spawn-locks are released on error paths so stalled agents no longer block new ones. Worktrees always include the full source tree. Heartbeat routing now reaches the correct registered agent name. A Playwright end-to-end suite covers the onboarding flow, and all test suites pass cleanly.

## How to update

```
cd ~/myos
./update.sh
```
