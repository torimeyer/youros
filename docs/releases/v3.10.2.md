# myOS v3.10.2

**Three quality fixes since 3.10.1.** No more double-firing "feature is live" modal, the Personal mode badge looks better in light theme, and auto-labeling works without an Anthropic API key.

## What's better

### "Your feature is live" only fires once
The modal that announces a finished spec used to pop twice for the same feature, and could re-appear after a demo reset. Now it dedups across both notification paths and keeps the in-memory record on demo reset, so each completed spec shows the modal exactly once.

### Personal mode badge color in light theme
The "Personal" pill in the sidebar was rendering as a harsh medium gray on the light-theme background. It now uses a soft slate that matches the rest of the sidebar.

### Auto-labeling works without an API key in Settings
The smart-labeling endpoints used to refuse if no Anthropic API key was saved in Settings. Now they accept a Claude Code login as well, so anyone signed in to Claude works.

## How to update

```
cd ~/myos
./update.sh
```
