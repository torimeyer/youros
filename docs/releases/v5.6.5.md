# v5.6.5 — Settings connection UI polish

## What changed

- **Connection headers now readable in light mode.** The Google, Slack, iMessage, and GitHub section headings inside the connections accordion were inheriting a gray text color in light mode. They now show dark text consistently across both light and dark themes.
- **GitHub now shows a Disconnect button when connected.** Previously the GitHub section appeared empty after connecting. It now shows a connected indicator and a Disconnect button, matching the Google connection pattern.
- **Slack token form inputs now visible in light mode.** The Access Token and App ID fields had white text on a light background. Text is now dark in light mode and light in dark mode.
