# myOS v3.4.0

The Year 1 roadmap, shipped in a day. 16 features across chat, email, calendar, mobile, push notifications, offline mode, three new integrations, and an intelligence layer.

## What you can do now that you couldn't before

**The AI remembers your conversations.** Start a new chat and it knows what you talked about last time. No more repeating context. Toggle this off in Settings if you want a blank slate.

**Turn emails into tasks.** Every email in the Gmail view has a "Create task" button. Click it and the AI extracts a title and description from the email.

**Turn meetings into tasks.** After viewing a meeting prep briefing, click "Create tasks from this briefing" and the AI pulls out action items and creates a task for each one.

**Use myOS on your phone.** Every page is now responsive. Chat goes full screen on mobile, buttons are sized for fingers, and nothing scrolls sideways. Works on tablets too.

**Get alerts when you're away.** Push notifications tell you when agents finish, tasks come due, or emails arrive. Works even with the browser tab closed. Enable from the notification bell.

**Keep working without internet.** Tasks and the dashboard load from cache when you're offline. Changes queue up and sync when connectivity returns.

**Connect Slack.** Browse channels, read messages, send replies, and create tasks from any Slack message. OAuth setup in Settings.

**Connect GitHub.** Link a repo with a personal access token. Import issues as tasks, or push myOS tasks back to GitHub as issues.

**Import from Linear or Jira.** Migrating? One click imports your issues with priorities, statuses, and labels mapped to myOS equivalents.

**Your briefing now has action buttons.** The daily briefing includes clickable actions: close a stale task, reply to an email, prep for a meeting. One click to act.

**Agents learn from their mistakes.** myOS tracks which agent setups work and which keep failing. Proven templates earn a green badge. Failing ones get specific fix suggestions.

**See related context on any task.** The new Related tab shows emails, calendar events, and Drive files connected to a task, found automatically by keyword matching.

## Under the hood: ostk 3.1.0

myOS now runs on ostk 3.1.0 (up from 2.5.0). This is a major kernel upgrade.

**Semantic search is real now.** Tasks, ideas, and files are indexed with a local embedding model (potion-base-8M, 31 MB). When you search, results are ranked by meaning, not just keywords.

**Signed governance documents.** Your ENTITYFILE is now Sigstore-attested. This is the cryptographic proof that your myOS instance belongs to you. Required for trust tier elevation.

**New kernel capabilities active:** context elision (smarter agent memory management), approval system with TTL-scoped grants, session lineage tracking (handoff chains between agents), and the `ostk kernel serve` MCP server for native tool integration.

**Coming next session:** ostk hooks that route all file and shell operations through the kernel for full audit capture. Already configured, waiting on a fresh session to activate.

## Improvements

- Enterprise setup is now a step-by-step wizard instead of a bare form.
- Chat model toggle (Claude/Gemini) moved from Settings into the chat input area.
- Recurring tasks moved from Settings to a new "Recurring" tab on the Tasks page, with one-click presets to get started.
- Every Settings section is now half-page width in a two-column grid.
- Purple buttons in Settings use bolder text for better readability.
- E2E smoke test now sweeps all test artifacts (tasks, labels, shares) at start and exit. No more orphaned test data.
- The `tori` terminal command now runs `ostk boot` before launching Claude Code.
- Three-year roadmap published to GitHub.
