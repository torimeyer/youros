# yourOS 5.5.0

A reliability release: your task list shows everything again, ghost sessions stay out of Active Sessions, and Atlassian setup handles split sites.

## Highlights

- **Your private content stays on your machine.** yourOS now has a built-in guard that stops your chats, notes, specs, and settings from ever being saved into the shared code, and writes your working files to your own computer instead.
- **Your task list is complete again.** Open tasks that had been moved into the archive during a daily cleanup were quietly dropping off the board. They now show up again. If your list looks longer than before, those tasks were always open.
- **Ghost sessions no longer show as running.** A stuck or stale agent session no longer appears as Running in Active Sessions. Live agents are kept, only confirmed dead ones are hidden.
- **Connect Confluence on its own site.** If your Confluence lives on a different site than Jira, you can now give it its own address when you connect Atlassian.

## Improvements

- **Clearer message when the AI model is unreachable.** Breaking a spec into tasks now fails fast with a plain message if the AI model cannot be reached, instead of hanging.
- **Tidier task rows.** Removed the dead drag handle. The task number is now the drag handle, and the status circle reads Mark done or Reopen.
- **Specs can track the files a requirement covers.** A requirement can list the files it covers, and the drift check now warns when one of those files is missing.

## Fixes

- **Backend test suite no longer wedges.** A shared rate-limit helper was leaking state between tests, which could freeze the full backend test run for over ten minutes. Tests are isolated now.
- **Lower-output agent runs are easier to spot.** Agent completions now carry a signal when an agent finished with little or no real work. Plus assorted test fixes.
