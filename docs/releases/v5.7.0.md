## What's new

- **Enhanced Light Mode Clarity**: Systematic audit and fix of contrast across all pages. Headers, inputs, and previews are now optimized for visibility on light backgrounds.
- **Global contrast safety net**: New CSS architecture ensures standard text elements maintain high contrast in light mode by default, preventing future regressions.
- **Unified Messaging Module**: The 'People' module has been renamed to 'Messages' to better reflect its function.
- **Clean Activity Feed**: Suppressed internal system noise and enriched task events with titles for better legibility.
- **UI Streamlining**: Retired the old notification bell as part of the move to real-time toasts and context-aware alerts.
