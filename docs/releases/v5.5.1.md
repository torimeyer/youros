# yourOS 5.5.1

A polish release on top of 5.5.0: new plans wait for your go-ahead before they move forward, compare mode answers your questions directly, and the app stays responsive when a lot is running at once.

## Highlights

- **New plans stay drafts until you say so.** When you start a new plan, yourOS still fills in the suggested details for you, but it no longer moves the plan forward on its own. The plan stays a draft until you choose to promote it, so you decide when it becomes real. This keeps to a simple rule: yourOS shows you what it would do, and waits for you to approve it.
- **Compare mode answers what you actually asked.** When you compare answers from more than one AI at the same time, each one now replies helpfully to your question instead of saying a tool is missing.
- **Steadier when lots is running at once.** yourOS no longer slows to a stop when many background helpers are working at the same time. The running-helpers list is lighter, and stale sessions are cleaned up, so the app stays responsive.

## Fixes

- **Creating then promoting a plan works every time.** Promoting a brand-new plan used to occasionally fail with a "draft not found" message because the file had already been moved. New plans now stay put until you promote them, so the step always succeeds.
- **Test suite and install check are green again.** The full backend and frontend test suites, plus the end-to-end install check, now pass cleanly, so each release can be verified before it ships.
