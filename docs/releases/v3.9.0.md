# yourOS v3.9.0

**Google Enterprise.** Four new features that connect Gmail, Calendar, and Drive into the core yourOS experience.

## New features

### Smart Email Triage
Reads your unread inbox, classifies each message against your current tasks and meetings, and recommends an action: reply, create a task, read later, or archive. You review the recommendations and apply them in one click.

- Endpoint: `POST /api/gmail/triage`
- Apply actions: `POST /api/gmail/triage/apply`
- 17 tests

### Calendar-Aware Task Prioritization
Before each meeting, surfaces which of your open tasks relate to that meeting's topic, attendees, or labels. After a meeting ends, nudges you to create follow-up tasks.

- Endpoint: `GET /api/meetings/upcoming-tasks`
- Per-meeting: `GET /api/meetings/{id}/tasks`
- Post-meeting nudge: `GET /api/meetings/{id}/nudge`
- 16 tests

### Drive-Linked Specs
Publish any spec to Google Docs with one click. Edits sync in both directions. Each spec tracks its linked Doc so you always know where to find the shared version.

- Publish: `POST /api/specs/{path}/publish`
- Sync: `POST /api/specs/{path}/sync`
- Pull: `POST /api/specs/{path}/pull`
- 16 tests

### Enhanced "What Changed While You Were Away"
The since-you-last-looked endpoint now includes three Google signals alongside agents and files: new unread emails, calendar events that already happened, and Drive files modified by collaborators. All fetched in parallel.

- 10 tests

## Bug fix

**Timezone parsing in query parameters.** The `+` in ISO timezone offsets like `+00:00` was being decoded as a space in URL query parameters, breaking date filtering. Fixed.
