# myOS v3.11.2

A small fix to the onboarding flow.

## What's New

### Onboarding no longer stuck on Loading
The "Your starter agents" step in the onboarding wizard could get stuck on "Loading..." forever if the suggestions request hung. It now times out after 10 seconds and shows an actionable error with a "Try again" button. Skip still works at any time.

## How to update

```
cd ~/myos
./update.sh
```
