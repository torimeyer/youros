## What's new

- **One-command install**: A single command now bootstraps the full yourOS environment. YOUROS_HOME is now the single root for all runtime state, and the installer verifies that chat and the health endpoint are both responding before finishing.
- **Spec board cleanup**: New endpoints let the spec board reconcile IDs and check status, making it easier to keep specs in sync with real work.
- **Ghost agents no longer inflate the badge**: Agents that are no longer running are excluded from the active session count, so the number on the badge matches what the Active Sessions list actually shows.
- **Reliable server cleanup on restart**: The background server process reaper now catches the uvicorn reloader parent process that lsof previously missed, preventing stale processes from blocking a fresh start.
- **Task ID consistency fixes**: Zero-padded task IDs are normalized consistently across the active store, reconciliation, shelve, and unshelve paths so tasks no longer go missing when IDs have leading zeros.
- **Agentfiles stay isolated**: Agent recipe files are seeded as copies rather than symlinks, preventing writes inside an agent session from spilling into shared locations.
- **Spec audit stage accuracy**: The spec audit now correctly reports a spec as complete when its status is set to complete or done.
- **Spawn limit corrected**: The agent spawn limit stays at 3 per burst. A false report that a prior fix had not shipped was corrected.
