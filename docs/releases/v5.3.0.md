# yourOS 5.3.0

A stability and specs-quality release, plus a few things you asked for directly.

## Highlights

- **Pick your model when you start an agent.** The spawn box now lets you choose Claude or Gemini, and starts on Claude. Before, it could only start Gemini.
- **More reliable backend.** Fixed a slowdown that could freeze the backend and force a restart every 30 seconds when the agent list refreshed. The list now stays fast.
- **Honest agent chat.** If you message an agent that has already finished or gone quiet, it now tells you so plainly instead of pretending it is ready and waiting.

## Improvements

- **Clearer spec labels.** "In Progress" now has its own color, so it no longer looks the same as the "Needs detail" tag.
- **Spec drift actions.** When a spec and the code have drifted apart, the review panel now offers two choices: update the spec to match the code, or keep it as is.
- **Text a task to your OS (early, off by default).** Early support for sending a short instruction by message to start or nudge an agent. It stays off until you turn it on.

## Fixes

- **Deleting a spec actually deletes it.** Removing a spec that lives in your personal folder now works, and it no longer reappears after a refresh.
- **Spec status stays correct.** Added checks so a deleted spec stays gone, a spec with a started task reads In Progress, and the task count shown matches the real number of tasks.
