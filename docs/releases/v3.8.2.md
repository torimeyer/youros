# yourOS v3.8.2

## Agent reliability

**Agents survive backend reloads.** When you save a file in the api/ folder, the backend restarts to pick up the change. Previously, that restart killed every running agent because they shared the same process group. Now each agent runs in its own session, so reloads only affect the backend itself.

**Failed agents show up immediately.** When an agent crashes on startup (bad auth, missing tools, CLI error), it used to sit in the Agents list as "running" for up to 5 minutes before the system noticed. Now it flips to "failed" within seconds, with the error message visible in the transcript.
