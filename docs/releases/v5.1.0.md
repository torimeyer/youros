# yourOS 5.1.0

A reliability and onboarding-quality release. The headline work fixes how yourOS detects which AI providers and accounts you already have connected, stops internal planning files from shipping to fresh installs, and removes a class of phantom "in progress" work.

## Connect-your-providers detection

- **Anthropic / Claude no longer asks for a key you already have.** When a working Claude sign-in or key is detected, onboarding now shows "connected" instead of dropping you on the paste-a-key screen. A detection that is still loading or that fails now shows a clear state instead of silently looking unconnected.
- **Vertex AI is detected from a normal Google sign-in.** Signing in with `gcloud` is enough; detection no longer required a specific company domain, and an expired sign-in now reads as "needs re-authentication" rather than "not set up."
- **Google Workspace shows as connected when it is.** Onboarding now reflects an existing Google connection instead of always offering "set up."
- **Jira/Confluence:** a Confluence site that isn't reachable is reported once instead of repeating the same warning on every sync, and connected Jira is surfaced.

## Fresh-install cleanliness

- Your personal specs and drafts stay on your machine. New installs no longer inherit internal planning documents that were previously bundled by mistake.

## Reliability

- Task status no longer sticks on "in progress" after the agent doing the work finishes or stops. Finished and stopped work clears correctly.
- Fixed a background test crash that could interrupt automated checks partway through.
- The settings/onboarding/navigation reorganization and page-shell migration are complete.

## Also in this line

- Faster, streaming file downloads.
- Slides preview and in-app Docs/Drive editing.
- A live activity feed that refreshes as agents work.
- Cleaner left navigation (Backlog removed) and an Inbox title that is readable in light mode.
- Internal: assertion-free test guard, document-draft scaffolding, and worktree tooling improvements.
