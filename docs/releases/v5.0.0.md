# yourOS v5.0.0

This is the **yourOS** release. The product is now vendor-neutral and carries a new name, on top of a full interface refresh and a big step up in speed, stability, and account integrations. It is the largest release since the project began: 125 changes since v4.1.0.

## The headline: a new name

- The product is now **yourOS** (previously ToriOS). The name change runs through the app: the navigation label, the browser tab title, and onboarding.
- Personal identity has been removed from the product so anyone can run it as their own. The repository URL and related settings are now configurable rather than hard-coded.
- If you are upgrading, onboarding runs once more so the new name takes effect.

## A refreshed, consistent interface

- Every main page (Gems, Projects, Drive, Gmail, and the rest) now shares one consistent page layout, so headers, spacing, and loading states look the same everywhere.
- Settings, onboarding, and the side navigation were reorganized so related things live together.
- The sidebar nav icons now have accent colors, and Activity moved into the sidebar so it is one click away.

## Much faster and steadier

- **The big one: the app no longer freezes for up to a minute.** Several things that used to block the whole app have been moved off the critical path, including logging, the active-sessions scan, and spec scans. The app stays responsive during normal use.
- The app now loads without spinning forever.
- Searching no longer hangs for 30 seconds when a background service is unavailable; it fails fast and moves on.

## Smoother onboarding

- The "where should your files go" step was removed. Files go to the standard yourOS folder, and you can change it later in Settings.
- The Connect step is clearer about the difference between choosing an AI provider and connecting your Google account, with step-by-step guidance.
- Starter agents moved into Settings instead of interrupting first-run.

## Connect your accounts

- Connecting Google or Gmail now returns you to the app correctly after sign-in instead of failing on the old address.
- A GitHub Connect button is available via a stable sign-in flow.
- Gmail now surfaces unread mail that is older than your 50 newest inbox items.
- Drive slide decks and documents open in the app, with basic in-app editing and a clear message if an edit cannot be saved.
- Calendar gained a New Event form with attendees, free or busy suggestions, and contact autocomplete.

## Live updates

- The Activity feed refreshes on its own the moment an agent finishes, instead of waiting on a slow poll.
- A new internal event system with server-sent updates powers this, replacing several older one-off channels.

## Tasks and projects

- The feature is now consistently called **Projects**, and the Projects page is reachable from the nav (it was previously orphaned).
- Task counts are honest, with a filter so child checklist items do not inflate the numbers.
- The Tasks view can include closed and done items, not just open ones.
- If an agent dies without finishing, its task returns to the To-Do column instead of getting stuck.

## Messaging and channels

- A channel parser previews what an inbound text would do (for example "spawn diagnose for Task 1654") in Settings. Inbound texts do not auto-run yet; that stays behind a consent toggle.
- Chat now queues fast back-to-back sends so they no longer collide.

## Under the hood

- New foundations for runtime providers and feature flags, a second-generation user-memory store, and a pattern-watcher that learns from your activity.
- A break-room arcade refresh with classic-style games.

## Fixes and quality

- Repaired 33 stale tests, tightened test isolation so tests no longer read your real data, and hardened the release smoke gate.
- Correctly detects a Claude subscription sign-in (a prior false negative in Settings).

## Upgrade notes

- yourOS runs on a single address (port 8000). The old separate dev port was retired back in v4.1.0.
- Onboarding will run once after upgrading so the rename and reorganized settings take effect.
