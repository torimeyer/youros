## What's new

### Files page
A new Files section shows your decisions, needles, and recent activity from `.ostk/` directly in the app. Three tabs, a search box, and a card per entry.

### iMessage contacts
myOS can now pull your macOS contacts so workflows address messages by name not phone number. Loaded from your local Contacts.app. Stays on your machine — there's a privacy note on the page.

### Usage page
The Costs page now shows your Claude Code subscription quota and Gemini equivalent next to the cost numbers, so you can see your model spend without leaving myOS.

### PDF and Word doc support for Gems
Drag in `.pdf` or `.docx` files for a Gem's knowledge base. myOS extracts the text and indexes it like any other document. No new dependencies, no extra setup.

### Rules page
A new `/settings/rules` page where every enforcement rule can be toggled on or off and tuned without touching JSON. Twenty-two old hook files were consolidated into nine. The sidebar now has a quick link to it.

### Delete-all-data button
Settings now has a danger-zone button to wipe your local myOS data. Surgical extract from a much larger draft PR; only the button + the existing backend `DELETE /settings/data` were brought in.

### Atlassian / Jira fix
Atlassian's `/search` endpoint was deprecated. We migrated to `/search/jql` POST so Jira imports keep working.

## Reliability

- **Backend wedge fewer**: the sidebar status dot tolerates brief blips and shows a tooltip with the actual state. A py-spy thread dump now lands before any wedge SIGKILL so causes are diagnosable.
- **Stale agent rows**: `/api/agents` no longer shows zombie rows from past sessions. Reaped worktrees and dead PIDs get filtered out on every poll.
- **Faster prompt header**: the per-prompt header hook went from 7s to 0.3s (22× faster). The deny-detector was scanning 274 files per turn.
- **Agent landing reports**: the per-session Monitor now reads the worktree branch (not just main) and uses HTTPS for the backend. Agents that finish in a worktree are surfaced immediately.
- **Subagent cwd guard**: new structural guard prevents subagents from leaking edits onto the parent repo when isolated in a worktree.
