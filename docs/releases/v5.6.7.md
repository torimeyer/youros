# v5.6.7 — iMessage contact resolution + Atlassian onboarding improvements

## What's new

- **iMessage contact names**: When sending iMessages via the chat agent, phone numbers are now resolved to contact names from your Contacts book so messages go to the right person.
- **Atlassian onboarding**: OAuth flow now supports separate Jira and Confluence URLs. The Confluence URL field is hidden by default and revealed via a toggle, matching the settings page behavior.
- **Onboarding wizard**: Starter agents (Customize) step re-added after the Profile step, letting users pick their initial agent set during setup.
