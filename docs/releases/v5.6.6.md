# v5.6.6 — InboundPoller + Jira signal sync

## What's new

### iMessage inbound routing (→2161)
- Added `InboundPoller` — polls the local iMessage database on a ~12s interval and routes new messages through the channel intent parser
- Off by default; enable via `inbound_imessage_routing_enabled` setting
- Uses a thread to avoid blocking the server event loop
- Honors the iMessage circuit breaker when open
- Baselines the cursor on first pass so no backlog is replayed on startup
- Added `ChannelRouter` class and `build_default_router()` factory to `channel_routing`

### Jira confidence and risk auto-sync (→2113)
- New `POST /api/atlassian/issues/{issue_key}/sync-signals` endpoint
- Reads real signals: running agents, recent commits, recently closed tasks
- Writes confidence and risk values back to the Jira issue via existing `write:jira-work` OAuth scope
- Custom field IDs resolved dynamically from Jira's fields response
