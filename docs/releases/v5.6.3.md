# v5.6.3 — Event loop fix: agent list no longer freezes the backend

**Released:** 2026-06-05

## Fix

Every 30 seconds, fetching the agent list triggered a file scan that held the Python GIL long enough to freeze the backend event loop entirely. Health probes would timeout, the watchdog would SIGKILL uvicorn, and the whole backend would restart.

This patch indexes JSONL candidates on startup and yields every 10 iterations during enrichment, keeping the event loop responsive.

- `GET /api/agents` stays under 200ms after cache expiry
- Health probe stays under 100ms during enrichment
- Backend no longer restarts itself during agent activity
