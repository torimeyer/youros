# yourOS 5.2.0

## Highlights

- **Executive Summary (new page).** One place that shows how your work is rolling up and whether each piece is on track, and drafts weekly confidence updates you can approve with one click. When no tracker is connected it shows a friendly "set this up" state and writes nothing.
- **Search across your sources.** A new cross-source search finds matches across your connected sources and shows where each result came from.

## Improvements

- Specs and drafts you create are now saved in your own private folder instead of the app's shared files.
- The top bar is cleaner: the large page title was removed.
- You are only asked about creating a spec for genuinely large work now, so small requests just get done.
- The task "waves" controls are simpler: a single "Update waves" button instead of duplicate menu entries.
- A promoted plan that has not started yet now reads "Ready" instead of "In Progress."
- Kanban task cards are easier to scan, with a clearer id, priority, and a short description.
- Helpful default rules are turned on for new setups.

## Fixes

- Search returns nothing instead of erroring when a source is briefly unavailable.
- Removed a duplicate task-count badge on spec rows.
- Test reliability improvements.
