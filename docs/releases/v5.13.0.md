The Portfolio page headlines this release: it now shows your real tasks and projects instead of internal checklist noise, and a new card lets you set up themes, the goals your work supports, like customer trust, so everything can roll up under them. Its status labels speak plainly: past due, waiting on other work, no activity for a week. The Specs page got tidier too: finished specs moved behind a Show history button so the list only shows work still in play, and the sidebar badge now counts every spec that is not done. And the AI suggest button in the clarity panel actually works now: it used to fail every time with a cryptic error because the app gave up waiting after 5 seconds while a normal answer takes about 6, so it now waits as long as it needs and shows a plain message with a Retry button if the backend is busy.

Reliability underneath: a helper that crashes mid-job can no longer mark its task as finished, only real saved work closes a task; workspace cleanup reads the backend's own list of finished states so nothing lingers after a helper is stopped; the health-check script no longer hides connection errors; and both test suites are fully green (7,089 backend checks and 3,237 frontend checks), including a fix for a hidden hang that wasted a full minute of every backend test run.
