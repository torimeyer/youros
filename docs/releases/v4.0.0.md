## What's new

### The product is now yourOS

The app rebrands from **myOS** to **yourOS**. The name change puts the listener at the center: when you say "yourOS" out loud, the person you're talking to pictures *their own* OS, not yours. The v7 sunset-disc logo and the tagline "an OS that knows you." land on the brand surfaces (sidebar, splash, About).

- **Every visible surface** says yourOS. Onboarding wizard, About panel (renamed to AboutYourOS), Drive folder "Save to yourOS", system prompt, release notes, manifest.
- **Internal plumbing stays myos as legacy**. The PM2 process names, environment variables, `~/.myos/` data directory, `com.myos.ostk-watchdog` launchd plist, and the `/api/health` service tag are all unchanged. Nothing in your data layout moves.
- **GitHub repo renamed** to `torimeyer/youros`. Old `torimeyer/myos` URLs auto-redirect. Local `origin` points at the new URL. Install scripts and README updated.
- **Drive folder** has an additive migration shim. New users get a "yourOS" folder; existing users keep their "myOS" folder via fallback lookup, and the in-app suggestion to rename appears as a dismissible card.

### Public face

- **Holding page** at `marketing/getyouros/` ready for Cloudflare Pages deployment on `getyouros.com`. Wordmark, sunset-disc colors, real Download CTA pointing at the GitHub releases page.
- **`your-os.net` and `yourus.us`** are defensive registrations on Tori's Cloudflare, both intended as 301 redirects to `getyouros.com`. Brand discipline doc at `docs/brand/url-conventions.md`.
- **Branch protection on main**: deletions restricted, force pushes blocked. PR-required intentionally not set so the solo + agent workflow keeps working.

### Reliability

- **Sidebar is resizable** with persistence to localStorage (`myos-sidebar-width`), matching how the chat panel resizes.
- **Calendar widget font** bumped one tier for readability.
- **Color pass** through light and dark mode: amber accents on the sun icon, emerald accents on Confluence widget, softer navy (`#13151c` vs the old `#020617`) for dark mode backgrounds.
- **Stale GeminiReadyChip test** updated to match the current NeedsClarityChip interface (testid renamed →1515).
- **B2 sed follow-up**: caught a case-insensitive QuickLook regex assertion that the rebrand sed pass missed.

### Known limits

- **Pre-push hook tarball check** still fires `darwin-universal HTTP 404` for ostk releases since ostk now publishes `aarch64-apple-darwin` tarballs. Known issue →1740. Doesn't affect installs.
- **Release notes "within 14 days" check** can warn if no recent UAT entry was added before tagging. Cosmetic.
