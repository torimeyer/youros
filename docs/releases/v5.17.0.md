# v5.17.0

- The board no longer declares quiet agents dead without real evidence, and an agent whose row was wrongly closed gets its own name back.
- Agent runs now count toward the savings page, which used to only count chat.
- The Settings page is decluttered: the features, shortcuts, tour, and texting sections are gone, and what remains sits in a tight two-column layout.
- The desktop notifications switch now explains in plain words why it cannot turn on, instead of silently flipping back off.
- Texting yourOS from your phone is fully removed, both the screens and the machinery behind them.
- Button icons and labels stay visible in light mode; one misnamed color setting was quietly repainting 137 places near-white.
- The Add tools list looks like the rest of the app.
- The tour starts from the sidebar, next to What's New.
- The agent workspace folder is one configurable setting and every spawn honors it.
- A task's code save point can be corrected when the board stamps the wrong one.
- Daily compression savings come from real recorded events, and the squash savings number finally receives real data instead of always adding zero.
- The tasks menu can start agents for every open task at once, and the redundant row checkboxes are gone.
- The Linear/Jira import endpoints left with their only caller.
- Agent hand-offs carry receipts and point at the original documents.
- Promoting a spec no longer copies its checkboxes into the task list, and the task count always means the Tasks page.
- A spec marked done shows plainly when its own checkboxes disagree, on the page and as one clear warning.
- The Specs page only lists real specs and reports strays.
- You can type /build and /diagnose in chat.
- Chat skills work the same no matter which AI runtime is selected.
- Agent spawning picks its vendor from your saved setting, not a hidden switch.
- An agent that finishes while still marked running keeps its final summary.
- Agents that only register still get a real transcript byte count.
- Agents spawned through the default path keep their safety rails.
- The savings card says why it is empty, its tips show real numbers, and the today window follows your local calendar day.
- The backend's overlapping event pipes merged into one shared stream.
- The crash screen recovers on its own from a stale-page crash after a dev server restart.
- Solitaire's double-click auto-move, drag and drop, and window-fill sizing are locked in by tests.
- The chat panel, task list, and agent cards stop redoing work on every screen refresh, and background feeds pause while the tab is hidden.
- The backend stops re-reading files it already has on the paths the app asks for constantly, and its startup cleanup no longer delays boot.
- Three unreachable pages and an unused access guard are deleted, and a link to the removed shortcuts section is fixed.
- 37 new tests cover pages and error paths that had none.
