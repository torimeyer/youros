# yourOS 5.6.0

A batch of polish and new features after the UAT pass: text each other to add tasks, chat works cleanly across multiple browser tabs, onboarding detects your existing connections automatically, and a set of display improvements throughout.

## Highlights

- **Add tasks by text message.** Send "add task: fix the login bug" to yourOS and it creates the task for you. Reply "list tasks" to see what's open. Works through your existing SMS setup.
- **Multiple browser tabs work.** When you have yourOS open in more than one tab, each tab now gets its own stream of responses. Before, opening a second tab would mix up the chat output.
- **Onboarding finds your existing connections.** The setup wizard now detects your saved API key, Google account, and Atlassian connection automatically on first load — so you are not asked to set up things that are already configured.

## Fixes and improvements

- **Google sign-in shows as configured when it is.** The onboarding step used to say "Google sign-in is not configured" even when your Google account was connected. It now checks the right place.
- **Jira and Confluence connect separately.** The Atlassian connect form now always shows separate URL fields for Jira and Confluence, so you can connect them independently.
- **Drive slide preview shows all slides.** Previewing a slide deck used to show only the first slide. It now loads the full presentation in an interactive viewer.
- **Roadmap opens directly.** After a roadmap agent finishes, an "Open roadmap file" link takes you straight to the file instead of the files list.
- **Tile contrast in light mode.** Connection cards and section headers in Settings, Messages, and Agents are now clearly visible in light mode instead of washed out.
- **Tasks menu cleaned up.** Removed "Quick build", renamed "Comprehensive build" to "Build", added "Set to in progress". The Draft filter pill is gone. Task title editing now opens a taller box so long titles are readable.
- **Label All works without an API key.** Label All now works when you are signed in through your Claude subscription, not only when you have a raw API key configured.
- **Gmail task creation stays reliable.** Creating a task from a Gmail message no longer shows an error if the response takes longer than 30 seconds.
- **Confluence recent pages are your pages.** The Confluence widget now shows pages you recently viewed, not pages modified recently by anyone.
- **Recent docs skips system folders.** Release notes and internal agent docs no longer show up in your Recent Docs list.
- **Settings: configurable projects folder.** You can now set the folder where yourOS looks for your project docs, separately from the files output folder.
- **Gemini: smarter provider selection.** yourOS now tries Vertex AI, then the Gemini CLI, then your API key in that order — and gives a clear message if the Vertex AI API is not enabled on your project.
