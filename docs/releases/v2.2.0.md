# myOS v2.2.0

A big release. Here's what's new.

## What you can do now that you couldn't before

**Click any file, see what's inside.** The Files page now opens a side pane when you click a file. It works for markdown, code, spreadsheets (xlsx, xls, csv with tabs for multiple sheets), Word docs, PowerPoint slides, PDFs, images, plain text, and code with syntax highlighting. Press Escape to close.

**Make your slides pretty with one click.** Open any PowerPoint file in the Files page and you'll see a "Make it pretty" button. Click it and Claude redesigns each slide with a better layout, color, and font. You see the original and the new version side by side and can accept or reject each one.

**myOS picks the right helper for you automatically.** Type a message like "spawn agents to fix the login bug" and a small "Using: saa" badge appears above the reply. myOS recognized that you wanted the saa helper and used it without you having to say so. Same for diagnose and elit. You can also create your own custom templates and myOS will use those too. Toggle this off in Settings under Smart suggestions if you ever want manual mode.

**Your tasks get labeled automatically.** Add a task and within a couple of seconds it picks up the closest label from the ones you already have. It only invents a new label if nothing existing fits. A small sparkle icon shows which labels were auto-applied. Click the x on any of them to remove it and that label will not come back.

**Ideas turn into the full list of tasks needed to ship them.** Click "Break into tasks" on an idea and Claude breaks it down into all the smaller pieces. If the idea is too vague to break down well, myOS asks you a clarifying question instead of guessing. Answer it and you get a clean list of tasks, each one auto-labeled.

**Use your Claude subscription instead of paying for API tokens.** If you have Claude Code installed and signed in, myOS now uses your subscription for chat by default. A small indicator below the chat input tells you which one is active ("Powered by your Claude subscription" or "Using Anthropic API"). Switch between them in Settings under Chat backend.

**Install on Linux without Homebrew.** myOS now installs cleanly on Ubuntu, Debian, Fedora, and Arch with no brew required. The installer lists the prereqs you need (python, node, git, curl) and lets you install them with whatever tool you already use. It does not run any system package managers on your behalf.

**Your settings follow you across browsers and devices.** Chat history, custom agent templates, accent color, the tour you finished, and the What's New badge you cleared all live on the server now. Open myOS in another browser and everything is right where you left it.

## Improvements

- Your chat messages now sit on the right side of the chat panel like iMessage. myOS replies stay on the left.
- New `update.sh` script and `myos-update` command for safely updating myOS without ever touching your local data. There's a guide at `docs/SAFE_UPDATE.md` with the full walkthrough.
- The install script now lists missing prereqs and exits cleanly instead of trying to install anything for you.
- The Agents page shows your background agents the moment they start, not after they finish.
- Comprehensive end-to-end test script at `scripts/e2e_smoke.sh`. Run it before any release to confirm everything is healthy.

## Bug fixes

- Background agents no longer get stuck showing as "running" forever after they finish.
- Empty chat replies are gone. If a chat response gets cut off, you now see a clear "Connection dropped" message instead of a blank bubble.
- Tasks created from ideas now get auto-labeled (used to skip this step).
- Old saved settings files automatically pick up new fields when you upgrade. No more losing access to a feature because your settings were saved before it existed.
- The chat backend no longer restarts itself every time a background agent edits a test file, so chat replies do not get cut off mid-stream by routine activity.

## Under the hood

- 675 backend tests passing
- 541 frontend tests passing
- New end-to-end smoke script with 18 live checks (HTTP, WebSocket, TypeScript build, full pytest, full vitest)
- Coverage at or above 80% for almost every new file
- Settings storage moved to the server, no longer in browser localStorage
- Auto-labeling extracted into a shared helper so every task creation path gets it for free

## How to update

```
cd ~/myos
./update.sh
```

Or if you prefer step by step, follow `docs/SAFE_UPDATE.md`. Either way, none of your local data (settings, chat history, tasks, labels) gets touched.
