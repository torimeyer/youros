# yourOS v3.11.3

A handful of onboarding additions, a cleaner footer and Settings layout, smarter chat behavior, and a quiet round of internal cleanup.

## What's New

### Connect more of your work in onboarding
The Connect step now offers Atlassian, GitHub, and Google Workspace setup cards so you can wire up Jira, Confluence, your repo, and Drive/Calendar/Gmail without leaving the wizard. The Atlassian card pre-fills the site URL when one is set in the environment.

### Global footer with About and Privacy
Every page now has a small footer with About and Privacy links, sticking to the bottom of the viewport.

### Settings reorganized
The Settings tabs were reordered, Notifications and ADHD were combined into one tab, and the Privacy tab was removed (its contents moved into About). The Developer tab also got a cleanup pass.

### "What's working" page now has the top bar
The What's Working page picked up the same top navigation bar as the rest of the app, so it no longer feels like a different surface.

### Chat picks up your Claude subscription automatically
When you sign in via claude.ai, chat now uses your subscription rather than your API key. No menu toggle needed.

### Better chat behavior on long answers
Chat used to send contradictory "Still working" and "Stopped after 25 steps" messages on the same turn. That's fixed. The step cap is also a bit higher and Claude now prefers reading the file before editing it, which catches more issues earlier.

### Gemini answers as Gemini
Removed an old instance name from the Gemini system prompt so it no longer leaks into identity questions.

## How to update

```
cd ~/myos
./update.sh
```
