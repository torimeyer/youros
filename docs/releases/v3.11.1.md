# myOS v3.11.1

A small follow-up to v3.11.0 with one user-facing fix and a public-install cleanup.

## What's New

### Gemini speaks as Gemini, more reliably
Stronger system prompt for the Gemini chat path. Gemini now opens with "I am Gemini, Google's AI model" when asked which AI it is, and is explicitly forbidden from describing itself as local, embedded, or built into anything. This addresses cases where Gemini denied being Gemini and claimed to be running locally inside myOS.

### Cleaner public install
Removed internal-only documents from the public install. Strategic narrative, internal diagnoses, and agent backup files no longer ship to colleagues. The repo's `docs/` now contains only user-facing material (release notes, setup guides, architecture overview).

## How to update

```
cd ~/myos
./update.sh
```
