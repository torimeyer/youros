# yourOS 5.4.0

An onboarding-quality release: setup is faster and clearer, plus agent teams and more honest spec status.

## Highlights

- **Onboarding finds your providers reliably.** The setup screen used to sometimes show "Could not check for a connected provider" because the check was too slow. It now warms up at startup and answers instantly, so that error is gone.
- **Clearer Google setup.** Google Cloud (Vertex AI) and the personal AI Studio key are now two separate cards with shorter instructions, so it is obvious which one you want.
- **Agent teams.** Agents can work together as a team with a shared task list and roles, with a team view on the Agents page.

## Improvements

- **"Pick a project" guidance for Vertex.** If you have signed in to Google Cloud but have not set a project yet, the card now says so and shows the exact command to finish, instead of looking like the sign-in did nothing.
- **Atlassian shown correctly.** The connection is now labeled Atlassian and shows both Jira and Confluence, not just Jira.
- **Spec status reflects finished work.** A spec whose acceptance criteria are all met no longer shows In Progress just because some old tasks were never closed.

## Fixes

- **Faster provider check.** The Google sign-in check could hang for many seconds and time out the setup screen. It is now capped and all checks run at once, with the result kept ready in the background.
