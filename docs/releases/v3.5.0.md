# yourOS v3.5.0

The release where yourOS stops pretending. Every feature you ask for now gets built by real AI agents doing real work.

## What you can do now that you couldn't before

**Real Build-it.** Write a spec, click Build-it, and real agents go off to write the code, edit the files, and close their tasks. Expect a few minutes instead of a few seconds. When the feature is ready, a notification tells you to try it. No more replay, no more theater.

**Know the moment a feature lands.** A celebration modal fires automatically when Build-it finishes so features never arrive silently. Even if you refreshed the page mid-build, the notification still fires as long as the build wrapped up within the last minute.

**Reliable calendar.** Events you create from chat show up on the Calendar tab right away, no reload needed. Deleting events works whether you made them in chat or directly in Google Calendar. The 5 second undo window no longer bounces deleted events back if something else syncs in the background.

**Side by side AI chat (infrastructure ready).** The chat panel can now stream both Claude and Gemini answers in parallel, each in its own column with a thinking indicator that appears the instant you hit send. Ask the same question to two models, compare answers, pick the best one. (Feature surfaces through the All pill when the spec lands.)

**Cleaner chat.** Chat responses no longer flicker or rewind while typing. The switch from plain streaming text to styled formatting happens with a quick fade so it feels clean. No more visual "type, delete, retype" jitter on any model.

## Improvements

- Guided tour now has 7 steps including Specs and Build-it. Tooltips flip to the opposite side of the screen if they would clip the top or bottom edge, so no step ever gets stuck off-screen.
- The Chat tour step no longer names a specific model. It says "mention a model by name to switch, like @claude or @gemini" so the copy reads the same whether you start on Claude or Gemini.
- Active Sessions cards on the dashboard now wrap long agent titles to two lines with hover-to-expand, instead of cutting titles off mid-word.
- Briefing no longer lists test tasks, scratch notes, or accidental long paste-ins as closed work. Only real tasks show up in the daily summary.
- Sidebar session count now counts only real sessions. Old background reload rows no longer inflate the number.
- When Claude uses tools in chat, it prefers ostk commands over raw shell tools for a cleaner, faster feel.
- Gmail empty state now has a Sync-now button so the first-run experience is one click.
- Gmail, Calendar, and Drive all share one polished "Connect Google" panel with the same setup guide, so the first-time flow is consistent across tabs.
- Every modal in the app now closes when you press Escape (13 new Escape handlers added in this release).
- Every page has been swept for mobile viewport fit. Your friend opening a share link on their phone sees a layout that respects the browser chrome instead of clipping behind it.
- All task labels dropped the sparkle icon clutter; labels read as clean pills.

## Bug fixes

- Calendar delete no longer bounces back when a background sync fires during the undo window.
- First paint of a Claude answer no longer flashes raw markdown before rendering. The render handoff is now a 200 millisecond crossfade.
- Spec status no longer reports "complete" when a linked task is actually still open. An asyncio lock in the task-close path prevents concurrent closes from clobbering each other.
- Release-notes modal no longer re-fires old celebrations after a reset. It seeds on mount from the current server state and only fires on genuine in-session transitions within a 60 second grace window.
- Frontend no longer lists `myos-api-*` backend reload rows as user sessions.
- Chat no longer leaks the literal `<function_calls>` XML into broadcast turns. When tools are disabled for a turn, the system prompt and prior tool-use blocks are both cleaned out so Claude cannot pattern-match into XML tool calls.
- ShareView no longer fires React unmount warnings when a user navigates away mid-fetch.

## Under the hood

- Complete removal of the demo prewarm scaffolding. Approximately 900 lines of pre-canned replay code, 1800 lines of demo-specific tests, the 180 second wall-clock cap, the force-Haiku branch, the demo-mode agent supervisor, and four schema fields (demo_mode, honor_explicit_model, deadline_seconds, ac_index) are gone. Six fleet agents with LIMIT demo_mode true had the line removed and now run as real agents.
- 2867 backend tests pass (pytest).
- 341 frontend tests pass across the ten files touched this release.
- TypeScript project builds clean.
- Every `myos-ephemeral-*` localStorage key is swept on onboarding reset, so new features using that prefix auto-clean without code changes.
- Hardcoded `/Users/torimeyer/` paths replaced with `Path.home()` and runtime-derived slugs so the app works for any username on any Mac.
- Version string no longer shows noisy git describe output like `pre-dry-run-91-g914586a` when the current commit is past a non-semver tag.

## How to update

```
cd ~/myos
./update.sh
```

None of your local data (settings, chat history, tasks, labels) gets touched.

After the update, if you see the old side-by-side chat feature still in your tree, you can ignore it. This release ships without that feature surfaced through the UI; the next time you ask me to build it, it will land as a real feature in your own codebase.
