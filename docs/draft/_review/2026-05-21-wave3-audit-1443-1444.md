## →1443 Jira ADF rendering

- **What it does:** Jira ticket descriptions and comments sometimes arrive as structured
  JSON (Atlassian Document Format) instead of HTML. Without this fix, that raw JSON
  object was shown to users as `[object Object]`. The fix adds `_adf_to_plain()` in
  `api/services/atlassian.py` — a recursive function that walks the ADF tree and pulls
  out readable text, handling paragraphs, bullet lists, mentions (`@Name`), and hard
  breaks. Descriptions and comment bodies both go through it as a fallback when the
  server-rendered HTML is absent.

- **Visible to user:** Yes — Jira ticket descriptions and comments that previously

## →1444 ETA pill / system-prompt time visibility

- **What it does:** Two related changes ship together:
  1. **System prompt hint** — The model is told to prefix replies with `~Nm` (e.g.
     "~2m — spawning the agent now") when it is about to call a tool that typically
     takes more than two seconds. Plain language, no statistics jargon.
  2. **TimePill UI component** — A small `~Nm` chip that appears next to agent rows on
     the Agents page and next to the build badge on the Comprehensive Build pill. It
     polls `/api/time/estimate/{opKind}` every 30 seconds and renders only when the
     backend has enough history to produce a meaningful estimate. Shows nothing until
     there is data.
