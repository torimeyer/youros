## Failure Detail

### `test_agent_time_hooks.py::TestAgentDurationStatsShim::test_shim_returns_time_estimate_when_available`

**Error:**
```
AssertionError: Shim should return Time primitive estimate (~120s) when history exists, got 511.
assert 511 == 120 ± 5
```

**Classification: PRE-EXISTING**

**Root cause:** This test seeds its own DB with a 120s record and expects `get_duration_stats()` to return that. However, `agent_duration_stats.py` has a `time_primitive` fast-path that calls `time_primitive.estimate("agent_spawn")` before consulting the test's seeded DB. In environments with real agent history (this machine has 511s in the live DB), the fast-path returns first and the test's seeded value is never reached.

**Evidence it's pre-existing, not merge-caused:**
- Last commit touching `test_agent_time_hooks.py`: `d8cf38a5` (phase-2 GREEN, before the merge window)
- Last commit touching `agent_duration_stats.py`: `6bc1b69b` (May 20, fix for a related but different test isolation issue)
- The 5 merged commits touched only: `api/routers/specs.py`, `api/services/receipts_gate.py`, `api/tests/test_receipts_gate.py`, `api/tests/conftest.py` — none of which affect this test
- The failure is environment-dependent (returns 511 = real system data), not deterministic on a clean machine
