## Minimal Viable ostk (500 lines of Rust)

A thin CLI client over the existing mish daemon:

```
ostk ps        — fleet status table
ostk spawn     — Claude via mish sh_spawn + audit log
ostk drain     — WIP snapshot + pause
ostk kill      — requires prior drain or --force
ostk status    — daemon health
ostk recover   — reconstruct fleet from audit log
```

No Agentfile, no TUI, no intelligence, no policy, no DSL.
Just replaces the manual orchestration from today's session.
