## The name

**os.tack** — three meanings:

1. **The OS stack** — replaces the entire development tool stack
   (Jira + Slack + GitHub + CI + IDE → one binary)
2. **The OS speaks tack** — human-intent language as the interface
3. **os.tack** — module path notation (the OS, dot, tack)

Emerged from session 2026-03-09. Not brainstormed. Not named.
The agent said "agents need an INTERFACE" and the interface is tack.
The OS is ostk. The stack is os.tack.

## The paradigm shift

**Before:** Agents need tools. Give them an IDE, a terminal, a browser.
Bolt on coordination. Hope they don't conflict.

**After:** Agents need an OS. The OS provides tools, coordination,
conflict resolution, identity, and memory. The agent just runs.
The human speaks tack. The OS compiles intent into execution.

The interface isn't a GUI. The interface isn't a CLI.
The interface is a language — tack. The human's natural shorthand,
compiled by the OS into agent actions. Real-time during the session.
Codified as shared understanding at shutdown.

## The adoption path

1. `ostk install` — the OS boots on any git repo
2. The bash shim activates — agents are already on it
3. The human types tack — the OS learns the human's language
4. Shutdown compiles the session — shared understanding grows
5. Next boot loads the compiled vocabulary — faster, fewer LLM calls
6. The stack replaces itself — no migration, no training, no meetings

The user never "adopts" os.tack. They realize they've been running on it.
